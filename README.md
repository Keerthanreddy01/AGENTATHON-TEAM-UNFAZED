 Real-time Visual Context Prototype

This repository contains a nested hackathon project for exploring a camera-based assistant UI. The app accesses a webcam and microphone, performs browser-side face detection, presents person/context overlays, and includes voice, conversation-history, and status UI. It was built around the idea of showing contextual notifications while a camera feed is active.

> **Prototype status:** The checked-in frontend includes a custom Node server with mock WebSocket responses. Do not assume that every displayed response is generated by a production AI service. Confirm backend/inference wiring before presenting this as a production system.

## Where the application lives

The application is nested under:

- `DUMMY/dummyrepo/gdg-hackathon/frontend/`

The repository root is a container for this nested project, so run commands from the frontend directory rather than the repository root.

## Stack

- Next.js App Router, React, TypeScript
- MediaPipe Tasks Vision for browser-side vision features
- Browser camera/microphone APIs
- WebSocket support through the custom Node server
- Tailwind CSS and reusable UI components

## Run locally

1. Install Node.js and pnpm.
2. Open a terminal in `DUMMY/dummyrepo/gdg-hackathon/frontend/`.
3. Run `pnpm install`.
4. Run `pnpm dev`.
5. Open `http://localhost:3000` and grant camera/microphone permissions when prompted.

Useful scripts: `pnpm build`, `pnpm lint`, and `pnpm start` (check the custom server configuration before relying on production mode).

## Main areas

- `app/page.tsx` — main camera experience
- `components/webcam-stream.tsx` — camera stream and visual overlays
- `hooks/` — face-detection and stream-related logic
- `server.js` — Next.js HTTP server and mock WebSocket responses
